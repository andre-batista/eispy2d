# GitHub Pages Branch

This branch is dedicated exclusively to **GitHub Pages** deployment.

## ⚠️ Important Notice

This branch contains only the files necessary for GitHub Pages hosting and should not be used for development purposes.

## Development

For active development, please use the `main` branch or other development branches. This branch is automatically updated through CI/CD processes or manual deployment scripts.

## Structure

This branch typically contains:
- Static HTML files
- CSS and JavaScript assets
- Documentation files
- Demo pages
- GitHub Pages configuration

---

**Note**: Do not make direct commits to this branch unless you are specifically deploying to GitHub Pages.
